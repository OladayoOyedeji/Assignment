Let $P(n) = (n \geq 1 4(1^3 + 2^3 + \cdots + n^3) = n^2(n+1)^2)$

\[

\]

$4(1) = 1(2)^2 4 = 4$

Hence $P(1)$ holds

\textsc{Inductive case.}
Assume $P(k)$ holds for $k > 1$
\[
P(k) = (k \geq 1 4(1^3 + 2^3 + \cdots + k^3) = k^2(k+1)^2)
\]

We will show $p(k+1)$ holds for $k+1 > 1$

$4(1^3 + 2^3 + \cdots + (k+1)^3) = 4(1^3 + 2^3 + \cdots + k^3) + 4(k+1)^3$

from $P(k)$ we know that $4(1^3 + 2^3 + \cdots + k^3) = k^2(k+1)^2$

$k^2(k+1)^2 + 4(k+1)^3 = (k+1)^2(k^2 + 4k + 4) = (k+1)^2(k+2)^2$

Hence $P(k+1)$ holds

Hence by Weak induction $P(n)$ holds
